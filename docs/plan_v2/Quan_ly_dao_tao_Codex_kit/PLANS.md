# PLANS.md

Dùng ExecPlan cho mỗi phase hoặc thay đổi liên quan auth, schema, upload, permission, email delivery, deployment hoặc nhiều route.

Mỗi plan phải có:
1. Goal
2. Current state
3. In scope
4. Out of scope
5. Dependencies
6. Data/schema impact
7. Security impact
8. Performance impact
9. Implementation steps
10. Verification
11. Acceptance criteria
12. Rollback
13. Open decisions

Plan là tài liệu sống. Nếu discovery khác giả định, cập nhật plan và ghi lý do.
Không đánh PASS nếu test không chạy.
