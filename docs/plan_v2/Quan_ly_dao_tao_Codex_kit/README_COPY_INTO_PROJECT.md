# Cách đưa vào project

Giải nén vào repository root:

```text
repo/
  AGENTS.md
  PLANS.md
  START_HERE_CODEX.md
  harness/
  docs/
    Ho_so_ke_hoach_nang_cap_quan_ly_dao_tao_2026/
```

Nếu repo đã có `AGENTS.md`, hợp nhất chứ không ghi đè.
